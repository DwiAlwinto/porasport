Keunggulan Fondasi Basis Data (PostgreSQL & Prisma ORM)

Database dirancang dengan prinsip integritas referensial ketat (ACID Compliant), bukan database dokumen sederhana. Berikut arsitektur kuncinya:

Integritas Transaksi
1. Proteksi Tumpang Tindih (Race Condition)

Tabel field_slots diproteksi oleh constraint komposit unik:

model FieldSlot { fieldId String date DateTime hour Int ... @@unique([fieldId, date, hour]) }

Artinya: Bila dua pengguna mengklik bayar di mikrodetik yang sama, mesin database hanya mengizinkan satu transaksi sukses dan menolak yang lainnya.

Regulasi Perda
2. Mesin Tarif Berkeadilan (Dynamic Rate)

Mendukung aturan retribusi daerah melalui tabel field_rates:

  • Pembedaan tarif Siang (Non-Peak) vs Malam (Peak Hour).
  • Kategori: AMATIR, PROFESIONAL, PERTANDINGAN, SOSIAL.
  • Fleksibilitas satuan: PER_JAM, PER_HARI, PER_PERTANDINGAN.
Keamanan Akun
3. Manajemen Sesi Stateless dengan Server Revocation (Tabel `revoked_sessions`)

Token otentikasi login admin dan penyewa menggunakan enkripsi HMAC-SHA256 berkinerja tinggi. Jika sewaktu-waktu akun dicurigai, Super Admin dapat mencabut sesi langsung dari server seketika tanpa harus merestart sistem.

🔗 Matriks Relasi, Kardinalitas & Strategi Integritas Referensial:

👤 User ➔ 🏟️ Venue 1 : N (One-to-Many)

Satu pengguna (mitra/dinas) dapat memiliki dan mengelola banyak fasilitas olahraga (GOR, Stadion).

onDelete: CASCADE FK: venues.ownerId ➔ users.id
👤 User ➔ 📑 Booking 1 : N (One-to-Many)

Satu pengguna masyarakat dapat melakukan banyak reservasi. Penting: Akun user diproteksi agar tidak bisa dihapus jika memiliki riwayat transaksi aktif.

onDelete: RESTRICT FK: bookings.userId ➔ users.id
🏟️ Venue ➔ ⚽ VenueField 1 : N (One-to-Many)

Satu kompleks olahraga (misal Stadion Wibawa Mukti) memiliki beberapa lapangan spesifik (Lapangan Utama, Lapangan Latihan A, Trek Atletik).

onDelete: CASCADE FK: venue_fields.venueId ➔ venues.id
⚽ VenueField ➔ 🏷️ FieldRate 1 : N (One-to-Many)

Satu lapangan memiliki matriks tarif berlapis sesuai Perda (harga siang, harga malam, kategori klub amatir vs pertandingan resmi).

onDelete: CASCADE FK: field_rates.fieldId ➔ venue_fields.id
⚽ VenueField ➔ ⏱️ FieldSlot 1 : N (One-to-Many)

Slot waktu harian (06:00-23:00) yang digenerate per tanggal dan diproteksi composite key [fieldId, date, hour] agar mustahil bentrok.

onDelete: CASCADE FK: field_slots.fieldId ➔ venue_fields.id
📑 Booking ➔ ⏱️ FieldSlot 1 : N (Zero-or-Many)

Pesanan mengunci slot waktu. Jika pesanan dibatalkan atau kadaluarsa (60 menit), relasi booking dilepas (SetNull) dan slot langsung kembali AVAILABLE.

onDelete: SET NULL FK: field_slots.bookingId ➔ bookings.id
📑 Booking ➔ 💳 Payment & Proof 1 : 1 (One-to-One)

Tiap booking memiliki satu rekonsiliasi pembayaran dan satu bukti upload struk transfer yang diuji oleh mesin Google Vision AI OCR.

onDelete: CASCADE FK: payments.bookingId, payment_proofs.bookingId
👤 User ➔ 🚫 RevokedSession 1 : N (One-to-Many)

Menampung ID sesi (sid) yang telah dicabut hak aksesnya oleh Super Admin secara seketika sebelum masa kedaluwarsa alami token habis.

onDelete: CASCADE FK: revoked_sessions.userId ➔ users.id

Arsitektur Sisi Backend: 3 Istilah Resmi & Standar Enterprise

Jika Anda ingin menjelaskannya kepada klien, pimpinan dinas, atau tim auditor teknis pemerintah, Anda dapat menggunakan 3 istilah resmi industri berikut:

Istilah Resmi Backend
1. Unified Full-Stack (Server Actions Architecture)

Di Next.js modern, Anda tidak perlu membuat server backend terpisah (seperti Express.js atau REST API terpisah). Frontend dan Backend disatukan secara terpadu dalam satu fondasi kode menggunakan konsep Server Actions ("use server").

Kelebihannya dibanding REST API biasa: Kode backend dipanggil langsung seperti memanggil fungsi biasa dari frontend, namun dieksekusi 100% aman di server. Tidak ada URL endpoint API publik yang bisa ditembak sembarangan oleh orang luar dari Postman atau Insomnia (Zero Secret Leak).
Istilah Resmi Portal Admin
2. Custom Tailored Admin CMS (Padanan Filament di Laravel)

Jika Filament di Laravel adalah Admin Panel Generator (panel bawaan template yang seragam dan kaku), maka di aplikasi ini portal adminnya adalah Custom Tailored Admin CMS:

  • Dibangun khusus (tailor-made) sesuai alur kerja birokrasi dan regulasi DISBUDPORA Kab. Bekasi.
  • Memiliki fitur khusus yang tidak ada di generator biasa: layar verifikasi AI OCR Side-by-Side (membandingkan struk transfer langsung berdampingan dengan hasil ekstrak AI), tombol Lock Maintenance Lapangan, dan generator Barcode QRIS dinamis.
Istilah Resmi Otentikasi
3. Stateless Signed Cookie Session (Session Revocation)

Bukan JWT biasa yang rawan dicuri di LocalStorage, melainkan sesi terenkripsi biner dengan tanda tangan kriptografi HMAC-SHA256 di dalam cookie HTTP-Only (SameSite=Lax).

Keunggulan Keamanan: Dilengkapi tabel revoked_sessions di database PostgreSQL yang memungkinkan Super Admin mencabut paksa sesi login penyewa atau admin bermasalah secara seketika dari sisi server (Instant Server-Side Revocation).

⚙️ Komponen Mesin Backend & Integritas Sistem Lainnya:

ORM & Database
Prisma ORM (v5)

Jembatan komunikasi antara kode program dengan PostgreSQL secara terstruktur. Menjamin proteksi 100% dari SQL Injection, mendukung migrasi otomatis, dan menjamin type safety hingga level kolom query.

Machine Learning
Google Cloud Vision AI Engine

Mesin kecerdasan buatan dari Google untuk memindai foto struk bukti transfer warga, mengekstrak angka nominal uang, tanggal transaksi, dan nama rekening secara otomatis untuk admin.

Otentikasi Publik
Google OAuth 2.0 Engine

Protokol resmi login & registrasi Google 1-klik dengan validasi state cryptographic anti-CSRF, berjalan mulus di localhost, staging, maupun domain produksi dinas.

Integritas Berkas
Binary Magic Bytes Inspector

Pemeriksaan header berkas biner asli (magic bytes FF D8 FF JPEG / 89 50 4E PNG) saat upload bukti transfer untuk menggagalkan skrip berbahaya atau shell injection.

Arsitektur Sisi Frontend (Antarmuka Pengguna & Interaktivitas)

Sisi antarmuka pengguna (Frontend) dibangun dengan standar kemewahan web modern berkecepatan tinggi, memanjakan warga saat mengakses dari smartphone maupun desktop kantor:

Core UI Framework
Next.js 16 & React 19

Menggunakan React Server Components (RSC) untuk rendering awal super cepat di server, dipadukan dengan Client Components untuk interaktivitas instan (pemilihan slot jam, kalkulator tagihan otomatis).

Modern Styling Engine
Tailwind CSS v4

Engine CSS utility generasi terbaru dengan kompilasi instan dan footprint CSS minimalis. Menerapkan desain mobile-first responsive dengan estetika warna premium (Emerald Dinas, Slate Elegan).

Ikonografi Tajam
Lucide React Icons

Koleksi ikon vektor modern yang konsisten, beresolusi tajam di layar Retina smartphone, memberikan kejelasan visual pada kategori olahraga, status booking, dan navigasi menu.

Micro-Animations
Motion (Framer Motion v13)

Animasi transisi halus saat modal checkout muncul, transisi tab tanggal jadwal bento, dan efek hover kartu stadion yang membuat antarmuka terasa dinamis, responsif, dan hidup.

Visualisasi Data Admin
Recharts v3 Library

Grafik analitik interaktif pada Dashboard Admin untuk memantau grafik penerimaan PAD harian/bulanan, tren jenis olahraga terpopuler, dan persentase okupansi fasilitas.

Zero-Defect Form
Strict TypeScript 5 & Masking

Form input kependudukan dilengkapi validasi format NIK 16 digit, masking nomor telepon WhatsApp, dan countdown timer pembayaran yang terisolasi aman dari error runtime.
